Border System
The entire visual hierarchy is built on borders, not cards or shadows. Eight distinct uses.
Weight Semantic Role Example
1px solid var(--border) Masthead bottom, column dividers, between sections
2px solid var(--ink) Widget/column title underline, editor toolbar bottom
3px solid var(--ink) Major structural break (section-bar top, expanded panel top, footer top)
3px solid var(--border-dark) <hr> thick rule
border-left: 3px solid var(--ink-muted) Code block accent (landing)
code block
border-left: 3px solid var(--border-dark) Code block accent (app markdown)
code block
border-left: 2px solid var(--ink) Sidebar active file
active file
border: 1px dashed var(--accent) Generate button

3px ink = major structural break. 2px ink = section label underline. 1px border = content divider.

Chain Adapter Pattern

The chain adapter is the only AI call boundary in Specview. Feature modules import only from chain/adapter.py — never from providers directly.

Core Functions

Three functions cover all use cases: generate(), stream(), and rewrite(). Builder and principles context are injected automatically in the first two.

Error Handling

All chain errors are ProviderError(msg, status). Catch this and nothing else.

from modules.runtime.chain.adapter import generate
result = generate(prompt, context=ctx)
The chain layer is a boundary, not an abstraction. It hides the provider, not the concept.
