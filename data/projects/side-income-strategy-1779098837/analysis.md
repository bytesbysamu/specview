# 🔍 Side Income Strategy — Analysis

## The Problem
Sam has five active projects, most requiring sustained consumer marketing to monetize — the exact distribution channel he identified as his bottleneck. The portfolio is optimized for what Sam enjoys building, not for what a solo dev with a day job can actually sell. Strategy and project list are misaligned.

## Hard Constraints
- Day job is primary income — side projects get nights/weekends only
- No existing audience, no marketing budget assumed
- Coding speed is not the lever — distribution speed is
- Telegram is the primary mobile interface (caps response formats)
- No external infra beyond Docker Compose → Coolify

## Open Questions
- **What happens to humanize-me?** It's live, consumer, in a saturated market. Kill it, milk existing traffic passively, or pivot to a B2B API?
- **What happens to Bubls?** Local consumer app in Zürich requires community-building hustle. Pause, geo-pivot, or kill?
- **Trendfy kill date passed — is it dead?** If yes, say so and stop carrying it in the portfolio. If no, what changed?
- **Revenue target?** "Side income" means different things. $500/mo and $5k/mo demand completely different product categories.
- **Is Sam willing to be the face?** Viral-by-output only works if yes. If no, strike it from the playbook entirely.
- **Which marketplace first?** Chrome Web Store, Shopify App Store, and MCP server registries have very different review cycles, WTP ceilings, and competition densities.

## Dependencies & Sequencing
- Revenue target must be set before any product selection — it filters entire categories
- Existing projects need a kill/keep/passive decision before starting anything new, or they'll keep bleeding attention
- OpenClaw + sam-plugin are infrastructure, not revenue — they only matter if a revenue product routes through them
- First marketplace product should ship before optimizing the agent platform

## Explicitly Out of Scope
- **Venture-scale planning** — no fundraising narratives, TAM analysis, or hockey-stick projections. Re-scope if Sam quits the day job.
- **Content-creator strategies** — no TikTok/IG growth playbooks unless Sam answers "yes" to being the face. Re-scope on that answer.
- **Multi-product portfolio optimization** — pick one revenue product, prove distribution, then diversify. Re-scope after first $1k/mo.
- **spec-doc monetization** — it's a dev tool for Sam, not a product. Re-scope only if external developers start requesting access unprompted.
