Bubls is an AI-curated event discovery app for Zürich that answers one question: "What should I do this weekend?" It delivers 5 AI-picked events every Thursday at 6pm via push notification, email, and app update. No searching, no scrolling — just 5 things worth doing, picked for you. The fundamental insight is that people don't want to search for events, they want someone to tell them what's good. The weekly cadence is a design constraint, not a limitation.

The competitive landscape confirms the gap: Eventbrite (acquired by Bending Spoons, revenue declining 12% YoY) gives you 400 results. Google's "Ask Maps" launched March 2026 as conversational event discovery but has no Swiss coverage. Fever creates its own events. Luma narrows to tech. Nobody owns general-purpose discovery for a real city. Zürich is the wedge — one city done well beats 50 done empty.

**Current state:** The app is fully built and shipped to TestFlight (v2.0.0 build 4) with 18 epics, 85+ tasks, ~18K lines in a single 42-hour session (April 16-18). The stack is Angular 20 + Ionic 8 + Capacitor 8 (frontend), Flask (backend), Neon Postgres (database). The app has four distinct visual "worlds" — /home (Sunday Magazine editorial picks), /photoshoot (Darkroom, LoRA inference with 3 modes and 7 models migrated from Trendfy), /text (Writer's Desk with humanize/chain ops), and /onboarding (3-step foyer). There is a full chain system for AI operations, RevenueCat for payments, voice input, haptics, SQLite, and a parallel spec-gen + task-exec pipeline built into the project itself.

The backend has a working chain system (definition_runner.py, braindump-to-docs, task-exec, verify.py with 5-check protocol), real Flask endpoints for photoshoot inference and text chains, a waitlist/tracking module, and a spec pipeline with 165 passing tests. Frontend has 300+ Karma tests. The iOS project migrated from SPM to CocoaPods with 15 pods.

**Key decisions already made:** Mock data first, real backend wired in now. Angular signals over NgRx. No user accounts — email + magic-link token is identity. Standalone components, no NgModules, OnPush change detection. German event titles preserved, English summaries. JSONB for feature flags. pgvector accumulated from day one for future personalization (two-pass curation: vector similarity pre-filter then Claude ranks top 15 into final 5). iOS only for v1 (Android same Capacitor build later). One screen + detail view — no external URL linking, Bubls owns the event data display.

**Open questions:** Does the Thursday push notification create habit? What's the CTR on the 5 picks (strongest PMF signal)? Will app store submission be approved given the limited initial content? Which distribution channel converts (r/zurich, expat WhatsApp groups, Luma community)?
