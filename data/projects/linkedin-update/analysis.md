# 🔍 LinkedIn Profile Rewrite – Analysis

**Purpose**: Surface the positioning decisions and constraints before writing copy.

**Date**: 2026-04-18

---

## Problem

Current LinkedIn profile says "Java/Angular developer." Actual identity is AI builder shipping SaaS products from brain dumps using a self-built methodology. Every profile visit reinforces the wrong positioning.

## Hard Constraints

- **220-character headline limit** — LinkedIn truncates at ~220 chars on desktop, ~120 on mobile. The core message must land in the first 120.
- **2,600-character about limit** — roughly 3 short paragraphs plus a CTA. No room for fluff.
- **No employer conflict** — copy must not create tension with any current employment context. Safest path: don't mention the employer at all unless it reinforces the builder narrative.
- **Credibility requires proof** — "AI builder" is a crowded self-label. The differentiator is the methodology + the numbers (18 epics, 42 hours, live products). These must appear early.

## Open Questions

| Question | Resolution |
|----------|------------|
| Mention employer or pure indie? | **Pure indie.** The audience (potential users, collaborators, AI-curious builders) doesn't care about employment context. Mentioning it dilutes the builder signal and creates a "is this a side project?" framing that undermines credibility. If someone needs the employment context, it's visible in the Experience section — the About is for positioning, not résumé. |
| Which products to name? | **Humaniz.me only** as the live-in-production proof point. Trendfy and others are pre-validation — naming them weakens the "shipped" claim. One live product with revenue context beats a list of MVPs. |
| Link to landing page or blog post? | **Both.** About section CTA links to the landing page (humaniz.me). Mention "THE post" (the methodology write-up) as the credibility anchor — link it or reference where to find it. |
| Include the "Five-Part Agent" framing? | **Yes, in headline.** This is the hook that makes the methodology tangible. "Brain dump → shipped product" is the promise. "Five-Part Agent" names the system. |
| Tone: technical or accessible? | **Accessible with technical proof.** The arc (Java → AI builder → methodology) is a story anyone can follow. The numbers (42 hours, 18 epics) are the technical proof that earns respect from builders. Don't write for recruiters — write for other builders and potential users. |

## Dependencies

- The "THE post" (methodology write-up) should be published or near-published before the profile goes live, so the reference has a destination.
- Humaniz.me landing page should be current — profile visitors will click through.

## Explicitly Out of Scope

- Experience section rewrite (separate task, lower leverage)
- Featured section curation (valuable but distinct)
- LinkedIn banner image (design task, not copy)
- Content strategy / posting cadence (ongoing, not a one-shot rewrite)
- Skills and endorsements cleanup
