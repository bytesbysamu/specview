## Overview

Every distribution post — Reddit, Twitter, Indie Hackers — links back to the GitHub profile. Right now the profile says nothing about the AI building methodology, shipped products, or the spec-doc pipeline that makes it all work. For the technical audience evaluating whether to follow, star, or use the tools, the profile is a dead end.

This capability turns the `bytesbysamu` GitHub profile into a landing page for builders. It pins the repos that matter (spec-doc, bubls), surfaces shipped products with real numbers ($195K MRR validated market, live production URLs), and frames the methodology (braindump → specs → code → product) as the throughline. The README is not a CV — it's a proof-of-work document that answers: "what has this person actually shipped, and how?"

The profile also needs to work as a funnel. Visitors who land from a distribution post should see the shipped products, understand the methodology in under 10 seconds, and have a clear next action (visit the landing page, star spec-doc, explore bubls).
