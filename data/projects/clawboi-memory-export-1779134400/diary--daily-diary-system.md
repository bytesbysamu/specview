# Daily Diary System

## Format

Each day: `YYYY-MM-DD.md`

### Template:
```markdown
# YYYY-MM-DD

## Mood: X/10

## What Happened

## What I'm Thinking About

## Wins

## Struggles

## Tomorrow's Priority
```

## Purpose
- Track feelings, prevent depression spirals
- Build self-awareness
- ClawBoi reads daily, discusses patterns, suggests adjustments
- Not static — we iterate based on what we learn
