ClawBoi is the planning and tooling repository for the ClawBoi ecosystem — the coordination layer between OpenClaw (the running AI agent on a VPS) and product work. It's not where OpenClaw lives (that's `/data/.openclaw/` on the VPS) but where decisions about how it gets used are made and documented. The core thesis: ClawBoi IS the automation layer. Products are simple frontends with payments. Don't rebuild what ClawBoi already does.

The architecture rethink was triggered by Constellation — a Spring Boot + Java project that was building LangChain4j, a Jobs system, Reddit adapters, and an Intelligence layer from scratch, all of which ClawBoi (OpenClaw) already provides natively via WebFetch, Bash, Claude, and Telegram. The decision: delete those Constellation components, keep only the Humaniz.me Flask API (~150 lines), Next.js frontend, Stripe, and Supabase auth. ClawBoi handles opportunity finding, content drafting, memory, multi-channel notifications, and scheduling via cron + hooks. Products stay thin.

**ClawMemory dashboard** is the concrete output that lives in this repo. It's a personal dashboard visualizing OpenClaw's memory data — diary entries, daily notes, mood trends, people extracted from entries. The dashboard uses a NYT newspaper aesthetic (Playfair Display + Source Serif 4, warm paper background, ink black, multi-column layout). Data flow: VPS ClawBoi container → sync.sh runs export-memory.py inside container → memory.json exported → app.js renders to HTML. Features shipped (March 11, 2026): lead story with direct quotes, entry slider, mood chart, people extraction (20 names, sorted by mention count), sticky nav, inline expansion, markdown rendering. Deployed via Docker Compose with Traefik to a Hostinger VPS.

**MemoryOS brainstorm** (March 18) is the more ambitious vision: a lightweight architecture combining ClawMemory + constellation-api LLM layer + FileWatcher. Key insight from that analysis — only ~30% of OpenClaw is actually used (Telegram input, memory markdown, Claude API). The rest (WhatsApp broken, Web UI broken, gateway/pairing complexity, multi-agent overhead) is overhead. The proposal: 50-line Telegram bot + constellation-api LLM for extraction/analysis + ClawMemory dashboard for output + FileWatcher for reactive updates = ~150-200 lines of new code. LLM used for extraction (DiaryParser, PeopleTracker, PatternFinder, DailyDigest), not conversation. Provider switchable via env var (Anthropic default, Groq free tier, Ollama local).

**Key decisions made:** DRY principle is non-negotiable — ClawBoi handles automation, products don't. Delete LangChain4j, Jobs system, Reddit adapters, Intelligence layer from Constellation. Keep Flask API, Stripe, Supabase in Constellation products. Telegram is the primary interaction channel for briefings and notifications. ClawBoi uses Claude's native capabilities directly, no abstraction needed.
