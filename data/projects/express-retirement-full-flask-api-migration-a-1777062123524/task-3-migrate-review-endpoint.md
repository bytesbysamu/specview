## 1. Context

`review_prompt()` already exists at `modules/ai/prompts/__init__.py:75` and is tested. The only moving parts are one schema block in `openapi.yaml`, a DTO regen, a ~20-line route handler in `routes.py`, and integration tests. The handler calls `chain_adapter.generate()` (context-injection path, not the edit-only `rewrite()` path), strips markdown fences inline with `re.sub`, and raises `AIProviderError("review_parse_failed")` on a `JSONDecodeError`. No proxy entry is added here — that happens atomically in Task 4 alongside `generate-spec`. Until then, Angular's `/api` fallback continues routing to Express (3100); Flask (3101) serves the route for direct HTTP testing only.

**Trade-offs considered**:
- **Shared fence-stripping utility** — rejected; `review` is the only consumer today. Extract when a second consumer materializes, calibrated by two real shapes.
- **Catching `KeyError` when accessing `parsed["scores"]`** — not added; Claude is instructed to return those keys. A `KeyError` here is a prompt failure; the observable 500 is the correct signal to investigate the prompt, not silent fallback.
- **`chain_adapter.rewrite()` instead of `generate()`** — rejected; `rewrite()` is the instruction-driven edit path. `generate()` is correct for new structured output, even when builder/principles kwargs are omitted (empty-string context injection is a no-op in `with_context`).

New handler (add after the closing line of `rewrite()`, before the trailing comment):

```python
@ai_bp.post("/review")
def review():
    req = ReviewRequest.model_validate(request.get_json(force=True, silent=False) or {})
    system, prompt = review_prompt(req.documents)
    try:
        try:
            result = chain_adapter.generate(system, prompt)
        except ProviderError as exc:
            raise AIProviderError(exc.message) from exc
        raw = re.sub(r'```(?:json)?\n?|\n?```', '', result.text).strip()
        try:
            parsed = json.loads(raw)
        except json.JSONDecodeError:
            raise AIProviderError("review_parse_failed")
        response = ReviewResponse(scores=parsed["scores"], issues=parsed["issues"])
        return jsonify(response.model_dump())
    except AIProviderError as exc:
        return jsonify({"error": str(exc), "status": 502}), 502
```
