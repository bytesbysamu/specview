When generating or bootstrapping a project in spec-doc, each epic needs the full set of spec documents: analysis.md, epic.md, architecture.md, timeline.md, spec-index.md — not just a README.md.

**Why:** The README is just an overview. The real value is in the structured spec docs (analysis of the problem, epic with tasks, architecture decisions, timeline for tracking). Without these, the project is incomplete and can't be executed.

**How to apply:** When creating or reviewing a spec-doc project, confirm all five core documents exist. A project with only a README is not considered bootstrapped.
