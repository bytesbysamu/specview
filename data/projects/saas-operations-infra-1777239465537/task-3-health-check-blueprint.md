# Task 3: Health Check Blueprint — Implementation Guide

## 1. Context

This task registers a stable `/api/health` Flask Blueprint inside `modules/observability/` with three independently addressable sub-routes: a live Anthropic probe at `/anthropic`, and permanent `{"status": "skipped"}` stubs at `/neon` and `/stripe`. The endpoint shape — not the live-check bodies — is the primary deliverable. Task 4's CI smoke test will write assertions against these exact routes before either Neon or Stripe is wired into spec-doc, so the response contract must be locked in and immutable from day one. The Anthropic probe routes through `modules/chain/adapter.py` per ELA #1 and wraps the call in a 5-second threading join so a degraded provider cannot hold the gunicorn worker indefinitely.

**Trade-offs considered:**
- **Call the Anthropic SDK directly inside `health.py`** — simpler probe path with no adapter overhead; rejected because ELA #1 is non-negotiable and the Architecture Design Principles table explicitly resolves the open question in favour of the adapter boundary. Any exception to ELA #1 requires a documented architectural decision, which this task does not carry authority to make.
- **Single `GET /api/health` route returning all three statuses in one JSON object** — reduces HTTP round trips; rejected because Task 4's smoke test and future uptime monitors need independently addressable routes to isolate which dependency is degraded without parsing a composite payload.
- **Thread-with-join timeout wrapping `adapter.generate()`** — chosen because it enforces the 5-second SLO without modifying the adapter's public signature, works identically with the CLI and SDK providers, and keeps `health.py` within the ~40 LOC budget while exposing a `PROBE_TIMEOUT` constant that tests can monkeypatch without coupling to implementation internals.

### Step 2: Create `modules/observability/health.py`

**Action**: Create the Blueprint. The `PROBE_TIMEOUT` module-level constant is the only externally visible knob; tests monkeypatch it rather than patching internal threading machinery.

**File**: `api/modules/observability/health.py` (new)

**Pattern**:

```python
import threading
from flask import Blueprint, jsonify
from modules.chain import adapter

PROBE_TIMEOUT = 5.0  # seconds; monkeypatch in tests to avoid slow assertions

health_bp = Blueprint("health", __name__, url_prefix="/api/health")


def _probe_anthropic(result: dict) -> None:
    """Run in a daemon thread; writes 'ok' or 'degraded' into result."""
    try:
        adapter.generate(system="ping", user="ping", max_tokens=1)
        result["status"] = "ok"
    except Exception:
        result["status"] = "degraded"


@health_bp.route("/anthropic")
def anthropic_health():
    result: dict = {}
    t = threading.Thread(target=_probe_anthropic, args=(result,), daemon=True)
    t.start()
    t.join(timeout=PROBE_TIMEOUT)
    if not result:
        return jsonify({"status": "degraded"}), 503
    status_code = 200 if result["status"] == "ok" else 503
    return jsonify(result), status_code


@health_bp.route("/neon")
def neon_health():
    return jsonify({"status": "skipped"}), 200


@health_bp.route("/stripe")
def stripe_health():
    return jsonify({"status": "skipped"}), 200
```

**Verify**: `python -c "from modules.observability.health import health_bp; print(health_bp.name)"` from `api/` — expect `health`.

```python
import time
import pytest
from unittest.mock import patch


class TestNeonHealth:
    def test_returns_skipped_status(self, client):
        resp = client.get("/api/health/neon")
        assert resp.status_code == 200
        assert resp.json["status"] == "skipped"

    def test_response_has_no_extra_keys(self, client):
        resp = client.get("/api/health/neon")
        assert set(resp.json.keys()) == {"status"}


class TestStripeHealth:
    def test_returns_skipped_status(self, client):
        resp = client.get("/api/health/stripe")
        assert resp.status_code == 200
        assert resp.json["status"] == "skipped"

    def test_response_has_no_extra_keys(self, client):
        resp = client.get("/api/health/stripe")
        assert set(resp.json.keys()) == {"status"}


class TestAnthropicHealth:
    def test_ok_when_adapter_succeeds(self, client):
        with patch("modules.observability.health.adapter.generate", return_value="pong"):
            resp = client.get("/api/health/anthropic")
        assert resp.status_code == 200
        assert resp.json["status"] == "ok"

    def test_degraded_when_adapter_raises(self, client):
        with patch(
            "modules.observability.health.adapter.generate",
            side_effect=RuntimeError("connection refused"),
        ):
            resp = client.get("/api/health/anthropic")
        assert resp.status_code == 503
        assert resp.json["status"] == "degraded"

    def test_degraded_on_timeout(self, client, monkeypatch):
        # Monkeypatch the timeout to 0.1 s so this test completes quickly.
        monkeypatch.setattr("modules.observability.health.PROBE_TIMEOUT", 0.1)

        def slow_generate(system, user, *, max_tokens):
            time.sleep(0.5)  # longer than the patched 0.1 s window
            return "pong"

        monkeypatch.setattr("modules.observability.health.adapter.generate", slow_generate)
        resp = client.get("/api/health/anthropic")
        assert resp.status_code == 503
        assert resp.json["status"] == "degraded"

    def test_response_has_no_extra_keys_on_ok(self, client):
        with patch("modules.observability.health.adapter.generate", return_value="pong"):
            resp = client.get("/api/health/anthropic")
        assert set(resp.json.keys()) == {"status"}


class TestHealthAdapterBoundary:
    """Structural: health module must not import from providers directly (ELA #1)."""

    def test_health_module_does_not_import_providers_directly(self):
        import subprocess

        result = subprocess.run(
            [
                "grep",
                "-r",
                "from modules.chain.providers",
                "modules/observability/",
            ],
            capture_output=True,
            text=True,
            cwd=".",  # run from api/
        )
        assert result.returncode != 0, (
            "modules/observability/ imports a provider directly — violates ELA #1. "
            f"Offending lines:\n{result.stdout}"
        )
```

## 10. Out of Scope

This task ships the endpoint shape and the Anthropic live probe. It does not activate, implement, or stub-replace any of the following deferred items:

- **Neon live health check** — Neon is not wired into spec-doc. Promoting the stub to a live check requires a Neon connection string, a connection pool, and a `SELECT 1` probe. Revisit when Neon is added as a dependency.
- **Stripe live health check** — same reason as Neon. Revisit when Stripe webhooks or payment logic land in spec-doc.
- **`/api/health` aggregate route** — a single endpoint returning all three statuses as a composite object. Not needed until Task 4's smoke test or a monitoring tool requests it; add it at that point without breaking the three sub-routes.
- **Auth middleware on health routes** — health routes are intentionally public (no bearer token required); adding auth would break CI smoke tests. If rate-limiting is needed, add it at the Coolify/Traefik layer, not here.
- **Uptime monitoring integration** (e.g., UptimeRobot, BetterStack) — the endpoint contract is stable enough to configure now, but the integration is an ops step, not a code step. Do it after Task 4 ships.
- **Structured log output from health routes** — structlog is initialized by Task 1, so log lines from `health.py` will automatically carry `request_id`. Explicit `logger.info(...)` calls inside the health routes are aesthetic polish; add them when observability is tuned, not now.

**Rule for the executor**: if a change appears helpful but is listed here, STOP and flag it as a deviation rather than expanding this task's blast radius.
