# One-Person Product Factory

i keep building products. in 2026 alone i've built or significantly worked on: specview (spec generation tool), bubls (event discovery app), humaniz.me (AI text humanizer), wardrobai/trendfy (AI fashion), openclaw/clawboi (personal AI agent), and a clawmemory dashboard. the pattern is clear: i build fast, ship to testflight or a VPS, then move on to the next thing.

the honest assessment: i'm great at building, terrible at selling. i have zero paying customers across all of these. the total revenue from my side projects is CHF 0.

what i actually have:
- a super-app shell (angular + ionic + capacitor) that can host multiple products
- a spec-generation pipeline that can plan any project in under a minute
- an AI agent (clawboi) running 24/7 that can automate tasks
- a VPS with docker compose deployment already working
- revenuecat for payments already integrated
- apple developer account, app on testflight
- full-stack skills (flask, angular, python, typescript, docker, postgres)

what's working as infrastructure:
- specview pipeline: braindump → analysis → epic → architecture → implementation guide (this is genuinely good)
- claude code as a build accelerator (42-hour bubls session proves the speed)
- docker compose + coolify for deployment
- neon postgres for databases

the core question: should i keep building new products or pick ONE and go all-in on distribution?

marc lou (shipfa.st guy) approach: build fast, launch on product hunt, iterate on what gets traction. but he has 400k twitter followers. i have zero audience.

my theory: i should use specview + claude code as a factory. the workflow:
1. identify a micro-niche with built-in distribution (chrome extension, shopify app, etc.)
2. braindump the idea into specview
3. generate full specs in 1 minute
4. build with claude code in 1-2 days
5. ship to the marketplace
6. if it gets traction, double down. if not, next.

but i've been saying this for months and haven't executed it.

what's actually blocking me:
- analysis paralysis: every idea seems equally good/bad
- the distribution problem isn't solved by building faster
- i get dopamine from building, not from the boring sales/marketing work
- i have no feedback loop from real users
- i'm scared of putting myself out there (cold emails, public launches, being visible)

questions:
- is the factory approach right or should i go all-in on one product?
- which existing product is closest to revenue?
- what's the minimum marketing i can do that actually works?
- should i target B2B (higher WTP, cold-emailable) or B2C (marketplace distribution)?
- how do i break the build-but-don't-sell cycle?
- what would a realistic "first CHF 1000" path look like from where i am now?
