# 🎯 Epic: Specview

## Business Value

Solo founders and small teams burn hours converting raw product thinking into structured specs, then burn hours more re-establishing conventions every time an AI agent touches the repo. Specview collapses both loops: a single `bootstrap-project` call turns a braindump into the full analysis → epic → architecture → timeline → implementation guide set, and a co-shipped Claude Code plugin encodes Flask/Angular/chain conventions once so every dev session auto-routes to the right reference, skill, or specialist agent.

The buyer is the documentation-first solo builder who already runs Claude Code locally and wants spec output that matches their stack's exact conventions — not generic markdown. Self-hosted on a Coolify VPS with markdown-on-disk storage means zero per-seat SaaS cost and full control over prompt chains. The plugin half compounds value: every spec generated by Specview is also implemented under Specview's own conventions, so the tool dogfoods itself.

The wedge is the pairing. Spec generators exist; convention-encoding plugins exist; nothing ships both wired into the same repo with a CLI-only AI path that runs inside Docker without outbound Anthropic access.

## Scope

### What This Epic Covers
- **Bootstrap pipeline** – `spec-pipeline` skill → `bootstrap-project` API → full spec folder at `data/spec-doc/projects/{slug}/`
- **Chain adapter (CLI-only)** – `chain/adapter.py` boundary, `CHAIN_PROVIDER=cli` wired through `chain-agent`, structural test pinning the boundary
- **Plugin references** – `plugin/references/*.md` as single source of truth for Flask, Angular, and chain conventions
- **Skill + agent surface** – 9 skills (`brainstorm`, `dev-build`, `dev-test`, `dev-migrate`, `dev-review`, `spec-pipeline`, `impl-guide`, `exec-guide`, `triage-projects`) and 4 agents (`chain-agent`, `spec-backend`, `spec-frontend`, `chain-developer`) routing per reference
- **Auth + usage gating** – `@require_auth` + `@check_usage_limit` on every AI route
- **Angular SPA (signals-only)** – braindump intake, spec viewing, project listing using `signal<T>()` / `computed()` / `@if` / `@for`
- **Docker Compose deploy** – Flask :3101, nginx web :8095, nginx landing :8096 locally; Traefik-routed on Coolify

### What This Epic Does NOT Cover
- ❌ **SDK provider path** — Docker container has no outbound Anthropic access; CLI is the contract
- ❌ **Database-backed spec storage** — markdown-on-disk only; revisit only if multi-user concurrent edits land
- ❌ **CI-triggered auto-deploy** — deferred open question; manual `git pull + compose build` for now
- ❌ **NgRx or external Angular state libs** — signals are non-negotiable
- ❌ **New skills/agents beyond the existing 9 + 4** — out of scope unless braindump explicitly adds one
- ❌ **Inline convention docs in skills/agents** — must cite `plugin/references/*.md`
- ❌ **Further modularization of `api/modules/ai/`** — open question, not MVP scope

## Success Criteria

- ✅ `bootstrap-project` accepts a braindump and writes analysis, epic, architecture, timeline, and implementation guide to `data/spec-doc/projects/{slug}/` in a single call
- ✅ `test_structural.py` fails any commit where a feature module imports from `providers/*` instead of `chain/adapter.py`
- ✅ `CHAIN_PROVIDER=cli` is the only provider path exercised in the Docker container; no SDK import in production code paths
- ✅ Every AI route returns 401 without auth and 429 once usage limit is hit
- ✅ Angular SPA renders intake + spec view with zero `BehaviorSubject`, `Observable` (for local state), `*ngIf`, or `*ngFor` occurrences
- ✅ All 9 skills and 4 agents cite a `plugin/references/*.md` rule rather than inline-duplicating it (grep audit passes)
- ✅ `dev-review` dispatches to `spec-backend`, `spec-frontend`, and `chain-developer` in parallel
- ✅ `docker compose up -d` brings Flask :3101, web :8095, and landing :8096 up locally; Coolify/Traefik routes on VPS without fixed host ports
- ✅ No direct master pushes — every change lands via PR with green pytest
