# Task 5: Project Repair Endpoint — Implementation Guide

## 1. Context

`POST /api/projects/<id>/repair` retroactively writes any of `spec-index.md`, `timeline.md`, and `README.md` that are absent from a project directory. Projects created before the linter and coherence-pass capabilities landed were bootstrapped without these structural files; the coherence pass will flag them as missing. The repair endpoint exposes the three deterministic generators already used by `bootstrap_project` (`generate_spec_index`, `generate_timeline`, `generate_readme` in `modules/templates/generators.py`) as an idempotent, on-demand operation scoped to the projects blueprint. It is architecturally isolated from the quality module — no AI calls, no lint/coherence logic — and has no ordering dependency on Tasks 1–4.

**Trade-offs considered:**

- **Streaming-/background-worker pattern (like `POST /generate-task`)** — rejected because repair is synchronous and fast (pure filesystem writes of three small markdown files; no AI call). A polling design would add latency and complexity for no benefit.
- **Separate repair module/blueprint** — rejected because the operation is a thin extension of the existing `modules/projects/` surface: it reuses `_safe_path`, the `project.json` reader, and `update_file`'s write semantics. Splitting it out would fragment a small feature across two modules.
- **Add `repair_project` to `modules/projects/service.py` + thin route in `routes.py`** — preferred because it follows the established service/route separation in the projects module, keeps the business logic testable without Flask, and reuses `_safe_path` without duplication.

```python
# Target filenames the repair endpoint is responsible for.
_REPAIR_TARGETS: list[str] = ["spec-index.md", "timeline.md", "README.md"]


def repair_project(projects_dir: Path, project_id: str) -> list[str] | None:
    """POST /api/projects/:id/repair — idempotent deterministic file repair.

    Writes spec-index.md, timeline.md, and README.md if absent.
    Returns the list of filenames written (empty list if all already present),
    or None if the project directory or project.json does not exist.

    Idempotency: runs twice on the same project produce the same filesystem
    state. Files present on the first run are not overwritten on the second.
    """
    project_path = _safe_path(projects_dir, project_id)
    meta_path = project_path / "project.json"
    if not project_path.exists() or not meta_path.exists():
        return None

    meta = json.loads(meta_path.read_text(encoding="utf-8"))
    project_name = meta["name"]

    generators: dict[str, object] = {
        "spec-index.md": lambda: generate_spec_index(project_name),
        "timeline.md": lambda: generate_timeline(project_name, []),
        "README.md": lambda: generate_readme(project_name),
    }

    repaired: list[str] = []
    for filename in _REPAIR_TARGETS:
        if not (project_path / filename).exists():
            content = generators[filename]()
            (project_path / filename).write_text(content, encoding="utf-8")
            repaired.append(filename)

    return repaired
```

> **Note on `generate_timeline(project_name, [])`**: The function accepts an empty tasks iterable and emits a placeholder backlog row (`| — | — | — | — | — |`). This is intentional — the goal is structural completeness for the coherence pass, not accurate backlog population. See `modules/templates/generators.py` line 106 for the empty-list branch.

```python
class TestRepairProjectService:
    """Service — repair_project: idempotent deterministic file repair."""

    def test_allFilesMissing_writesAllThreeAndReturnsThem(self, make_project_dir):
        root = make_project_dir("My Project", {"epic.md": "# Epic"})
        result = repairProject(root, "my-project-1700000000000")
        assert result is not None, "repair_project must return a list, not None"
        assert set(result) == {"spec-index.md", "timeline.md", "README.md"}
        project_path = root / "my-project-1700000000000"

        assert (project_path / "timeline.md").exists(), "timeline.md must be written"

            "My Project",

                "epic.md": "# Epic",
                "spec-index.md": "# Existing Index",
                "timeline.md": "# Existing Timeline",
                "README.md": "# Existing Readme",
            },
        )

        result = repairProject(root, "my-project-1700000000000")

        assert "spec-index.md" not in result, "present file must not appear in repaired list"

        first = repairProject(root, "my-project-1700000000000")
```

## 10. Out of Scope

This task adds a single idempotent repair endpoint with no AI call and no auth check. Several adjacent capabilities are explicitly excluded:

- **Auth / project-ownership check** — the existing API has no auth layer on any route (`modules/projects/routes.py` lines 37–83 are all public). The architecture identifies this as an open question but no pattern exists to implement against. Adding auth here before a global auth strategy is decided would produce inconsistent behavior across endpoints. Deferred until auth is designed system-wide.
- **Parsing `epic.md` to extract tasks for `generate_timeline`** — the timeline generator accepts a `tasks` iterable; passing `[]` produces a valid structural document with a placeholder backlog row. Populating the backlog from an existing epic would require `bootstrap_extract_tasks` (in `modules/ai/routes.py`), which introduces an AI-module dependency and parsing risk. Deferred: the goal is structural completeness, not backlog accuracy.
- **Angular UI integration** — the endpoint ships headless. Wiring it to the project-card coherence badge is a UI-layer concern belonging to the follow-up epic referenced in the architecture's "Excluded" table.
- **Repair of arbitrary filenames beyond the three targets** — the architecture explicitly scopes repair to `spec-index.md`, `timeline.md`, and `README.md`. Extending this to task guide files or `analysis.md` would require AI generation and is a different problem class.
- **Coherence endpoint (`POST /api/projects/<id>/coherence`)** — a distinct endpoint consuming `modules/quality/coherence.py` (Task 4). This task does not create `modules/quality/` and must not stub or partially implement it.
