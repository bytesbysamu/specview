# Task 3 — Add Cost Accumulator and `/api/ai/stats` Endpoint

**Effort**: 0.3 days

## 1. Context

After Tasks 1 and 2, the SDK provider returns token usage and the adapter auto-selects it in production. Nothing yet aggregates those numbers. This task adds a module-level accumulator (`_USAGE` dict + `threading.Lock`) inside `runtime/chain/adapter.py`, calls `_record_usage(result)` after every successful provider call, and exposes the running totals via a new HTTP endpoint `GET /api/ai/stats`.

The accumulator is org-wide and resets on process restart — ELA #7. Per-tenant attribution belongs to the usage-metering capability, not here. Pricing constants live alongside the accumulator so a price change is one file edit; pricing is keyed by model id so per-step routing in Task 4 is correctly costed without any extra plumbing.

The endpoint is added to `openapi.yaml` first; DTOs are regenerated; the route handler validates against the generated DTO. New Blueprint `stats_bp` lives at `modules/ai/routes/stats.py` and is registered in `create_app.ENABLED_MODULES`.

### Step 2: Add the accumulator to the adapter

**File**: `{WORKSPACE}/api/modules/runtime/chain/adapter.py`

**Pattern** (append below `_select_provider`):

```python
import threading

# In-process org-wide AI usage accumulator. Resets on process restart.
# ELA #7 — single consumer (the /api/ai/stats route), no Redis, no DB.
_USAGE_LOCK = threading.Lock()
_USAGE: dict = {
    "calls": 0,
    "input_tokens": 0,
    "output_tokens": 0,
    # Per-model cumulative totals so cost can be recomputed if pricing changes.
    "by_model": {},  # model_id -> {"input_tokens": int, "output_tokens": int}
}

# Per-million-token pricing in USD. Hard-coded; revisit when Anthropic
# changes prices. Keep in sync with the model ids referenced in
# modules/ai/workflows/* AICall steps.
_PRICING: dict = {
    "claude-sonnet-4-5": (3.00, 15.00),
    "claude-haiku-4-5":  (0.80, 4.00),
    "claude-opus-4-7":   (15.00, 75.00),
}

# Used when a model id has no entry in _PRICING — usage is still recorded,
# cost contribution is zero rather than a crash.
_UNKNOWN_MODEL_PRICING = (0.0, 0.0)


def _record_usage(model: str, result: ChainResult) -> None:
    """Add this result's tokens to the org-wide accumulator. Lock-protected."""
    with _USAGE_LOCK:
        _USAGE["calls"] += 1
        _USAGE["input_tokens"] += result.tokens_in or 0
        _USAGE["output_tokens"] += result.tokens_out or 0
        bucket = _USAGE["by_model"].setdefault(
            model, {"input_tokens": 0, "output_tokens": 0}
        )
        bucket["input_tokens"] += result.tokens_in or 0
        bucket["output_tokens"] += result.tokens_out or 0


def get_usage_summary() -> dict:
    """Return a snapshot of cumulative usage. Cost is computed from _PRICING."""
    with _USAGE_LOCK:
        cost_usd = 0.0
        for model_id, totals in _USAGE["by_model"].items():
            in_rate, out_rate = _PRICING.get(model_id, _UNKNOWN_MODEL_PRICING)
            cost_usd += totals["input_tokens"] / 1_000_000 * in_rate
            cost_usd += totals["output_tokens"] / 1_000_000 * out_rate
        return {
            "calls": _USAGE["calls"],
            "input_tokens": _USAGE["input_tokens"],
            "output_tokens": _USAGE["output_tokens"],
            "cost_usd": round(cost_usd, 4),
            "provider": _resolve_provider_name(),
        }
```

Then call `_record_usage(model, result)` at the end of `generate` and `rewrite`, after the `ChainResult` is constructed and before `return`. Stream is unchanged in this task.

### Step 3: Add the Blueprint and route

```python
"""GET /api/ai/stats — org-wide AI usage and cost snapshot.

ELA #2: route file owns no business logic. Aggregation lives in
runtime/chain/adapter.py; this module only marshals the snapshot to JSON.
"""
from __future__ import annotations

from flask import Blueprint, jsonify

from dtos.models import AiStatsResponse
from modules.runtime.chain import adapter

stats_bp = Blueprint("stats", __name__)


@stats_bp.get("/api/ai/stats")
def get_ai_stats():
    snapshot = adapter.get_usage_summary()
    # Validate against the generated DTO so contract drift fails the test
    # suite, not a downstream consumer.
    payload = AiStatsResponse(**snapshot)
    return jsonify(payload.model_dump())
```

### Step 4: Tests for the accumulator

**File**: `{WORKSPACE}/api/modules/runtime/chain/tests/test_adapter.py`

**Pattern** (append):

```python
import threading

from modules.runtime.chain.types import ChainResult


def _reset_usage():
    from modules.runtime.chain import adapter as a
    with a._USAGE_LOCK:
        a._USAGE["calls"] = 0
        a._USAGE["input_tokens"] = 0
        a._USAGE["output_tokens"] = 0
        a._USAGE["by_model"].clear()


def test_record_usage_accumulates_tokens(monkeypatch):
    _reset_usage()
    r = ChainResult(text="ok", latency_ms=1, tokens_in=100, tokens_out=20)
    adapter._record_usage("claude-sonnet-4-5", r)
    adapter._record_usage("claude-sonnet-4-5", r)
    summary = adapter.get_usage_summary()
    assert summary["calls"] == 2
    assert summary["input_tokens"] == 200
    assert summary["output_tokens"] == 40
    # 200/1e6 * 3 + 40/1e6 * 15 = 0.0006 + 0.0006 = 0.0012
    assert summary["cost_usd"] == 0.0012


def test_get_usage_summary_uses_per_model_pricing(monkeypatch):
    _reset_usage()
    adapter._record_usage(
        "claude-haiku-4-5",
        ChainResult(text="x", latency_ms=1, tokens_in=1_000_000, tokens_out=0),
    )
    adapter._record_usage(
        "claude-opus-4-7",
        ChainResult(text="x", latency_ms=1, tokens_in=0, tokens_out=1_000_000),
    )
    summary = adapter.get_usage_summary()
    # haiku in: 1e6/1e6 * 0.80 = 0.80
    # opus  out: 1e6/1e6 * 75.00 = 75.00
    assert summary["cost_usd"] == 75.80
    assert summary["calls"] == 2


def test_record_usage_handles_none_tokens(monkeypatch):
    _reset_usage()
    r = ChainResult(text="cli result", latency_ms=1, tokens_in=None, tokens_out=None)
    adapter._record_usage("claude-sonnet-4-5", r)
    summary = adapter.get_usage_summary()
    assert summary["calls"] == 1
    assert summary["input_tokens"] == 0
    assert summary["output_tokens"] == 0
    assert summary["cost_usd"] == 0.0


def test_record_usage_unknown_model_does_not_crash():
    _reset_usage()
    r = ChainResult(text="x", latency_ms=1, tokens_in=10, tokens_out=10)
    adapter._record_usage("claude-future-99", r)
    summary = adapter.get_usage_summary()
    assert summary["calls"] == 1
    assert summary["cost_usd"] == 0.0


def test_record_usage_is_thread_safe_smoke():
    _reset_usage()

    def worker():
        for _ in range(100):
            adapter._record_usage(
                "claude-sonnet-4-5",
                ChainResult(text="x", latency_ms=1, tokens_in=1, tokens_out=1),
            )

    threads = [threading.Thread(target=worker) for _ in range(8)]
    for t in threads:
        t.start()
    for t in threads:
        t.join()

    summary = adapter.get_usage_summary()
    assert summary["calls"] == 800
    assert summary["input_tokens"] == 800
    assert summary["output_tokens"] == 800
```

## 9. Deviations Allowed

- **`AiStatsResponse` validation fails after a real model id is added later**: extend `_PRICING` for the new model rather than removing the validation. Unknown-model defensive path keeps cost calculation alive even if `_PRICING` lags briefly.
- **Tests need a way to reset `_USAGE` between cases**: use the `_reset_usage()` helper shown above. Do NOT introduce an exported `reset_usage()` function — accumulator mutation outside test scope is not part of the public surface.
- **DTO regeneration changes unrelated lines**: that means another openapi edit landed without DTO regeneration upstream; flag it as a separate cleanup commit and only stage the additive `AiStatsResponse` lines in this task.
- **Route placement is contested** (`/api/stats` vs `/api/ai/stats`): architecture's Open Question #2 picks `/api/ai/stats` for now. Re-decide only when a non-AI cost surface emerges.
