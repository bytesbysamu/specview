# Task 4: Write `test_contract.py`

**Purpose**: Produce the permanent live-server compatibility suite — 13 pytest tests that call Flask on 3101, deserialize each response into a Pydantic DTO, and assert meaningful invariants. A full passing run is the compatibility certificate that proves Flask is a drop-in for Express.

**Dependencies**: Tasks 1 (`openapi.yaml`), 2 (`flask/dto.py`), and 3 (`capture.py` + `flask/tests/fixtures/`) should be complete. This guide includes concrete fallbacks for all three if they are not.

## 1. Context

`test_contract.py` is a live-server suite — it uses `requests.Session` against `localhost:3101`, not the Flask test client. Each of the 13 tests calls one endpoint, instantiates the relevant Pydantic DTO from `flask/dto.py`, and asserts one or two invariants on top of the shape validation that Pydantic performs automatically. If Flask's response drops a required field, the `ValidationError` fires before any assertion runs, naming the exact field. CRUD tests that touch the project store (GET, PUT, DELETE by ID) borrow the project ID from `flask/tests/fixtures/project.json` rather than creating their own data, keeping tests order-independent. The DELETE test is the single exception — it creates its own short-lived project so the fixture project is never destroyed.

**Trade-offs considered:**
- **Flask test client (`client` fixture from `conftest.py`)** — rejected; it bypasses the real network stack and CORS headers, so a passing test-client run would not prove Express → Flask drop-in compatibility on a live port
- **Parametrize all context routes into two tests** — rejected; pytest counts parametrized variants as separate nodes, causing the reported test count to diverge from the "13 total" intent in the epic; discrete functions produce unambiguous output
- **`requests.Session` pointed at `localhost:3101`** — preferred; matches the architecture's design, reuses one connection across the session, and is the simplest harness for a live integration gate

from __future__ import annotations

from typing import List

from pydantic import BaseModel


class SpecSummary(BaseModel):

    label: str
    content: str


class ProjectSummary(BaseModel):

### Step 3: Write `flask/tests/test_contract.py`

**Action**: Create the contract test file with 13 discrete test functions plus the `flask` and `fixture_project_id` session-scoped fixtures.

**File**: `flask/tests/test_contract.py` (new)

**Pattern** (complete implementation — port verbatim):
```python
"""
test_contract.py — Live-server compatibility suite for Flask on port 3101.

Prerequisites
-------------
- Flask running on localhost:3101:
    cd flask && python app.py
- flask/dto.py present (Task 2, or Step 1 fallback)
- flask/tests/fixtures/project.json present (Task 3, or Step 2 fallback)

Run
---
cd flask && python -m pytest tests/test_contract.py -v
"""
import json
import sys
from pathlib import Path

import pytest
import requests

# Allow `from dto import ...` without installing flask/ as a package.
# Mirrors the pattern in flask/tests/conftest.py:5.
sys.path.insert(0, str(Path(__file__).resolve().parent.parent))

from dto import (
    ContextFile,
    Health,
    MutationResult,
    Project,
    ProjectCreated,
    ProjectSummary,
)

BASE = "http://localhost:3101"
FIXTURES = Path(__file__).resolve().parent / "fixtures"


# ---------------------------------------------------------------------------
# Session-scoped fixtures
# ---------------------------------------------------------------------------


@pytest.fixture(scope="session")
def flask():
    """requests.Session pointed at Flask on localhost:3101."""
    session = requests.Session()
    yield session
    session.close()


@pytest.fixture(scope="session")
def fixture_project_id():
    """Stable project ID from committed fixture (produced by capture.py or Step 2)."""
    path = FIXTURES / "project.json"
    assert path.exists(), f"Missing {path} — run capture.py or follow Step 2 in the task guide"
    data = json.loads(path.read_text())
    assert "id" in data and len(data["id"]) > 0, "fixtures/project.json must have a non-empty 'id'"
    return data["id"]


# ---------------------------------------------------------------------------
# 1 — Health
# ---------------------------------------------------------------------------


def test_health(flask):
    r = flask.get(f"{BASE}/health")
    assert r.status_code == 200
    dto = Health(**r.json())
    assert dto.status == "ok"


# ---------------------------------------------------------------------------
# 2 — List projects
# ---------------------------------------------------------------------------


def test_list_projects(flask, fixture_project_id):
    r = flask.get(f"{BASE}/api/projects")
    assert r.status_code == 200
    body = r.json()
    assert isinstance(body, list)
    summaries = [ProjectSummary(**item) for item in body]
    ids = [s.id for s in summaries]
    assert fixture_project_id in ids, (
        f"Fixture project {fixture_project_id!r} absent from /api/projects. "
        "Re-run capture.py or update fixtures/project.json."
    )


# ---------------------------------------------------------------------------
# 3 — Create project
# ---------------------------------------------------------------------------


def test_create_project(flask):
    r = flask.post(
        f"{BASE}/api/projects",
        json={
            "name": "contract-smoke",
            "files": [{"filename": "epic.md", "content": "# Contract smoke test"}],
        },
    )
    assert r.status_code == 201
    dto = ProjectCreated(**r.json())
    assert dto.name == "contract-smoke"
    assert len(dto.id) > 0
    assert len(dto.createdAt) > 0
    # Cleanup so the project does not pollute subsequent runs
    cleanup = flask.delete(f"{BASE}/api/projects/{dto.id}")
    assert cleanup.status_code == 200


# ---------------------------------------------------------------------------
# 4 — Get project by ID
# ---------------------------------------------------------------------------


def test_get_project(flask, fixture_project_id):
    r = flask.get(f"{BASE}/api/projects/{fixture_project_id}")
    assert r.status_code == 200
    dto = Project(**r.json())
    assert dto.id == fixture_project_id
    assert len(dto.name) > 0
    assert isinstance(dto.specs, list)


# ---------------------------------------------------------------------------
# 5 — Update project file
# ---------------------------------------------------------------------------


def test_update_project_file(flask, fixture_project_id):
    # Fetch current state to get a valid filename and restore content after
    get_r = flask.get(f"{BASE}/api/projects/{fixture_project_id}")
    assert get_r.status_code == 200
    project = Project(**get_r.json())
    assert len(project.specs) > 0, (
        "Fixture project has no files — re-run capture.py with a project that has specs"
    )
    filename = project.specs[0].filename
    original = project.specs[0].content

    put_r = flask.put(
        f"{BASE}/api/projects/{fixture_project_id}/files/{filename}",
        json={"content": f"# contract-test write\n\n{original}"},
    )
    assert put_r.status_code == 200
    dto = MutationResult(**put_r.json())
    assert dto.success is True

    # Restore so subsequent runs see the same initial state
    restore = flask.put(
        f"{BASE}/api/projects/{fixture_project_id}/files/{filename}",
        json={"content": original},
    )
    assert restore.status_code == 200


# ---------------------------------------------------------------------------
# 6 — Delete project (uses its own short-lived project; never deletes fixture)
# ---------------------------------------------------------------------------


def test_delete_project(flask):
    create_r = flask.post(
        f"{BASE}/api/projects",
        json={"name": "delete-me", "files": [{"filename": "epic.md", "content": "# delete"}]},
    )
    assert create_r.status_code == 201
    project_id = create_r.json()["id"]

    delete_r = flask.delete(f"{BASE}/api/projects/{project_id}")
    assert delete_r.status_code == 200
    dto = MutationResult(**delete_r.json())
    assert dto.success is True

    # Confirm 404 on subsequent GET — project must be gone
    get_r = flask.get(f"{BASE}/api/projects/{project_id}")
    assert get_r.status_code == 404


# ---------------------------------------------------------------------------
# 7–10 — Context GET (one function per endpoint, matching api-contract.md)
# ---------------------------------------------------------------------------


def test_get_builder(flask):
    r = flask.get(f"{BASE}/api/builder")
    assert r.status_code == 200
    dto = ContextFile(**r.json())
    assert isinstance(dto.content, str)
    assert isinstance(dto.exists, bool)


def test_get_principles(flask):
    r = flask.get(f"{BASE}/api/principles")
    assert r.status_code == 200
    dto = ContextFile(**r.json())
    assert isinstance(dto.content, str)
    assert isinstance(dto.exists, bool)


def test_get_codebase(flask):
    r = flask.get(f"{BASE}/api/codebase")
    assert r.status_code == 200
    dto = ContextFile(**r.json())
    assert isinstance(dto.content, str)
    assert isinstance(dto.exists, bool)


def test_get_references(flask):
    r = flask.get(f"{BASE}/api/references")
    assert r.status_code == 200
    dto = ContextFile(**r.json())
    assert isinstance(dto.content, str)
    assert isinstance(dto.exists, bool)


# ---------------------------------------------------------------------------
# 11–13 — Context PUT (read → write sentinel → assert → restore)
# ---------------------------------------------------------------------------


def _roundtrip_put(session: requests.Session, path: str) -> None:
    """Read current content, write a sentinel, assert success, restore original."""
    get_r = session.get(f"{BASE}{path}")
    assert get_r.status_code == 200
    original = get_r.json()["content"]

    put_r = session.put(f"{BASE}{path}", json={"content": f"# contract-test\n\n{original}"})
    assert put_r.status_code == 200
    dto = MutationResult(**put_r.json())
    assert dto.success is True

    # Restore — failure here does NOT fail the test (teardown best-effort)
    session.put(f"{BASE}{path}", json={"content": original})


def test_put_builder(flask):
    _roundtrip_put(flask, "/api/builder")


def test_put_principles(flask):
    _roundtrip_put(flask, "/api/principles")


def test_put_codebase(flask):
    _roundtrip_put(flask, "/api/codebase")
```

## 5. Tests

The test file IS the tests for this task — each function below is a complete assertion body. Framework: `pytest` + `requests`, matching the repo's existing test runner (`flask/tests/test_health.py`, `test_project.py`).

All test bodies are in Step 3 above. For reference, the three structural patterns used:

**DTO deserialization as assertion (shape check)**:
```python
def test_health(flask):
    r = flask.get(f"{BASE}/health")
    assert r.status_code == 200
    dto = Health(**r.json())          # ValidationError here means shape mismatch
    assert dto.status == "ok"         # invariant on top of shape check
```

**CRUD with fixture seed (no create/teardown)**:
```python
def test_get_project(flask, fixture_project_id):
    r = flask.get(f"{BASE}/api/projects/{fixture_project_id}")
    assert r.status_code == 200
    dto = Project(**r.json())         # SpecDetail items validated recursively
    assert dto.id == fixture_project_id
    assert len(dto.name) > 0
    assert isinstance(dto.specs, list)
```

**Self-contained CRUD (creates and tears down its own data)**:
```python
def test_delete_project(flask):
    create_r = flask.post(
        f"{BASE}/api/projects",
        json={"name": "delete-me", "files": [{"filename": "epic.md", "content": "# delete"}]},
    )
    assert create_r.status_code == 201
    project_id = create_r.json()["id"]
    delete_r = flask.delete(f"{BASE}/api/projects/{project_id}")
    assert delete_r.status_code == 200
    dto = MutationResult(**delete_r.json())
    assert dto.success is True
    get_r = flask.get(f"{BASE}/api/projects/{project_id}")
    assert get_r.status_code == 404   # deleted project must not be retrievable
```

## 10. Out of Scope

This task writes a baseline compatibility gate — one test per endpoint, DTO shape validation, minimal invariants. It does not expand into error-path coverage, performance assertions, or any changes to Flask route handlers. The following are explicitly deferred and should not be absorbed into this task even if they appear adjacent:

- **`PUT /api/references` test** — deferred pending confirmation that `api-contract.md` includes it as a named route; add only if confirmed
- **Error-contract tests** (4xx/5xx responses for malformed input, missing IDs, auth failures) — belong in a dedicated `test_error_contract.py`; no trigger condition defined yet
- **CI integration for `test_contract.py`** — requires a running Flask service in CI; should be scoped when the Express → Flask cutover is scheduled
- **`capture.py` in CI** — explicitly excluded per architecture; `capture.py` is a one-time operation, not a CI step
- **Pydantic validation in Flask route handlers** — architecture explicitly defers this until untrusted external consumers exist; do not add request validation to routes while implementing this task
- **`openapi.yaml` authoring** (Task 1) — if absent, this guide's `flask/dto.py` fallback is sufficient for `test_contract.py` to run; `openapi.yaml` should be authored as a separate task
