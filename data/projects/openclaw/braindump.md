OpenClaw is a personal AI assistant you run on your own devices — it answers you on the messaging channels you already use (WhatsApp, Telegram, Slack, Discord, Signal, iMessage, Google Chat, Microsoft Teams, Matrix, and 15+ more). It can speak and listen on macOS/iOS/Android, render a live Canvas, and run real tasks on a real computer. The gateway is the control plane; the product is the assistant. It's a serious open-source project with corporate sponsors (OpenAI, GitHub, NVIDIA, Vercel, Blacksmith, Convex) and companion apps across macOS, iOS, and Android.

This is not Sam's personal project — this is an open-source project Sam contributes to or maintains. The AGENTS.md/CLAUDE.md is a contributor guide, not a personal spec doc. The project evolved through several names: Warelay → Clawdbot → Moltbot → OpenClaw. TypeScript + ESM throughout. Node 22+ runtime. pnpm (with Bun also supported). Vitest for tests, Oxlint + Oxfmt for linting/formatting. Docs hosted on Mintlify at docs.openclaw.ai. Plugin ecosystem published to ClawHub (clawhub.ai). MCP integration via the mcporter bridge (github.com/steipete/mcporter) rather than baking it into core.

**Architecture:** Extension-agnostic core with a strict plugin boundary. Core knows about the Plugin SDK (`src/plugin-sdk/*`) but never imports from bundled plugin internals. Channels, providers, and capabilities register through manifest metadata and typed contracts. The Gateway runs as a menubar app on macOS (not a separate LaunchAgent). Plugin SDK is the only cross-package contract — extensions cross into core only through `openclaw/plugin-sdk/*`. Architecture has explicit boundary documents in `AGENTS.md` files at each subsystem (bundled-plugin-tree, `src/plugin-sdk`, `src/channels`, `src/plugins`, `src/gateway/protocol`). Prompt-cache stability is treated as correctness, not cosmetic — request assembly must be deterministic.

**Swabble** is a Swift 6.2 sub-project: a wake-word hook daemon for macOS 26 using Speech.framework on-device models. Default wake word is "clawd" (aliases "claude"). Runs local-only, zero network usage. Shared SwabbleKit target is multi-platform. Hooks run any command post-wake-word with cooldown, min_chars, timeout. launchd service stubs for start/stop/install.

**Current focus (per VISION.md):** Security and safe defaults, bug fixes, stability, setup reliability and first-run UX. Next priorities: all major model providers, major messaging channels, performance + test infrastructure, computer-use and agent harness capabilities, ergonomics across CLI and web frontend, companion apps on all platforms.

**Key decisions:** Terminal-first setup (explicit security posture before convenience wrappers). MCP via bridge model, not first-class runtime. New skills go to ClawHub first, not core. No agent-hierarchy frameworks (manager-of-managers) as default architecture. No full-doc translation sets in this repo (AI-generated translations via pipeline into `openclaw/docs` sibling repo). i18n for control UI is generated in-repo via `pnpm ui:i18n:sync`.

**Key operational rules for contributors:** One PR = one issue/topic. PRs over 5K lines reviewed only in exceptional circumstances. Pre-commit hook runs `pnpm format` + `pnpm check`. Hard gate: if change affects build output or published surfaces, `pnpm build` must pass. Multi-agent safety rules are strict — no git stash, no branch switches, no worktree changes unless explicitly requested. Release and publish are always explicit-approval actions. Version must be bumped in 6 places simultaneously (package.json, Android build.gradle, iOS Info.plist x2, macOS Info.plist, docs/install/updating.md).
