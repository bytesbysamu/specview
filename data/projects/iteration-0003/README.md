## Vision

```
Brain Dump → Specs → Claude Code → Working Product
```

The spec IS the source code. Code is derived.

## What This Is

A browser-based Markdown editor where:
- Text operations replace chat
- AI transforms documents in place
- Specs become actionable, not just readable

## Key Principles

1. **Document-first** — No chat. Edit the document directly.
2. **Specs as source** — Markdown files are the source of truth.
3. **Local-first** — Files on disk. Git-versioned.
4. **AI operations** — Rewrite, expand, compress, clarify, generate.
